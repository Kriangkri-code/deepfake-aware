🔒 ความปลอดภัยดิจิทัล (Digital Security)

ความเสี่ยงและมาตรการป้องกัน

ความเสี่ยงมาตรการป้องกันที่ตรงกับความเสี่ยง
1. การโทรหรือวิดีโอคอลหลอกโอนเงินด้วยเสียงหรือใบหน้าปลอม
มิจฉาชีพโคลนเสียงหรือใบหน้าของพ่อแม่ เพื่อน หรือครู แล้วอ้างเรื่องเร่งด่วนเพื่อขอเงิน		 • ตั้ง "รหัสลับครอบครัว" ไว้ถามเมื่อมีการขอเงิน
• วางสาย แล้วโทรกลับเบอร์เดิมที่บันทึกไว้เสมอ
• สังเกตการเร่งเร้า ห้ามบอกใคร หรือการเปลี่ยนบัญชีรับเงิน ซึ่งเป็นสัญญาณอันตราย
2. ภาพส่วนตัวถูกนำไปทำ Deepfake (รวมถึงภาพอนาจารปลอมและการแบล็กเมล์)
ใช้รูปจากโซเชียลที่เปิดสาธารณะ		 • ตั้งบัญชีเป็นส่วนตัว และจำกัดคนที่เห็นรูปหรือสตอรี่
• หลีกเลี่ยงการโพสต์ภาพหน้าตรงความละเอียดสูงจำนวนมาก และคลิปเสียงยาว ๆ แบบสาธารณะ
• ไม่รับแอดหรือวิดีโอคอลจากคนแปลกหน้า
3. ข่าวปลอมหรือคลิปปลอมของบุคคลสาธารณะ
ทำให้เข้าใจผิดและแชร์ต่อ		 • ตรวจสอบแหล่งที่มา และค้นหาจากสำนักข่าวที่เชื่อถือได้
• สังเกตปากไม่ตรงเสียง การกะพริบตาแปลก หรือขอบหน้าเบลอ
• ใช้ Reverse Image Search และ "หยุดก่อนแชร์"

เช็กลิสต์จับผิด Deepfake 🔍

👄 ปากและเสียง

ริมฝีปากไม่ตรงคำพูด น้ำเสียงราบเรียบ ไม่มีจังหวะหายใจ

👁️ ดวงตาและใบหน้า

กะพริบตาน้อยหรือผิดจังหวะ ผิวเรียบเกินจริง แสงเงาไม่สมดุล

🧏 ขอบและการเคลื่อนไหว

ขอบใบหน้า ผม หรือแว่นเบลอเมื่อหันข้าง ลองขอให้อีกฝ่ายหันข้างหรือโบกมือผ่านหน้า

⚠️ Deepfake รุ่นใหม่เนียนขึ้นเรื่อย ๆ การจับผิดด้วยตาจึงไม่พอ ต้อง ยืนยันผ่านช่องทางอื่น ทุกครั้งที่เกี่ยวกับเงินหรือข้อมูลสำคัญ

ลำดับการรับมือเบื้องต้นเมื่อเกิดเหตุ

  1. หยุด และตั้งสติ — อย่าโอนเงิน อย่าตอบโต้ และอย่าทำตามคำขู่ของผู้แบล็กเมล์
  2. เก็บหลักฐาน — แคปหน้าจอ บันทึกลิงก์ URL ชื่อบัญชี วันเวลา และสลิปการโอน (ถ้ามี) ก่อนที่โพสต์จะถูกลบ
  3. แจ้งผู้ใหญ่ที่ไว้ใจ — ผู้ปกครอง ครู หรือครูแนะแนว ไม่ต้องเผชิญเรื่องนี้คนเดียว
  4. รายงานแพลตฟอร์ม — ใช้ปุ่ม Report และขอลบเนื้อหาที่ละเมิด
  5. ถ้าโอนเงินไปแล้ว — โทรแจ้งธนาคารทันที และโทรสายด่วน 1441 (ศูนย์ AOC) เพื่ออายัดบัญชี
  6. แจ้งความ — ที่ thaipoliceonline.go.th หรือที่สถานีตำรวจ (ความผิดตามมาตรา 16 ต้องร้องทุกข์ภายใน 3 เดือน)
  7. ดูแลจิตใจ — หากเครียดหรือกังวล โทรสายด่วนสุขภาพจิต 1323
